Nama Bot & Credit

Nama & signature yang tampil di setiap balasan bot. Kosongkan untuk pakai default ("Muter Assistant").

Chat Personal (DM)

Kalau aktif, bot juga merespon chat pribadi (bukan cuma grup) memakai mode trigger & model default di bawah.

Aktifkan AI di chat personal

Mode Trigger AI (default)

Berlaku untuk chat personal, dan untuk grup yang belum di-override sendiri di tab Grup.

Model AI (default)

Nama model yang dipakai kalau grup tidak set model sendiri. Kosongkan untuk pakai default dari env (AI_MODEL).

API Key & Base URL AI

Override API key/endpoint chat AI tanpa edit .env. Kosongkan untuk pakai default dari env (AI_API_KEY / AI_BASE_URL).

System Prompt AI (tambahan)

Instruksi tambahan yang disisipkan ke system prompt bawaan bot (tidak menggantikan aturan dasar, hanya menambah).
